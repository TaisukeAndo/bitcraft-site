Prompt Security Filter

AIへの情報漏洩を、ローカルで検知・防止する。

Overview

ChatGPT・Claude・Geminiへのプロンプトに、
個人情報や機密情報が含まれていませんか？

Prompt Security Filter は、主要AIサービスへ送るプロンプトや画像に個人情報・機密情報が含まれていないかをリアルタイムで検知するセキュリティツールです。すべての検知処理は各PCのローカル環境内で完結するため、検知データがクラウドに送信されることはありません。Chrome拡張機能とローカルプロキシのハイブリッド構成により、WebブラウザからCLIツールまで幅広く対応します。

Problem

こんなお悩みはありませんか？

AI利用が広がるほど、情報漏洩のリスクは増加します。

01

個人情報の
意図しない送信

社員が顧客の氏名・住所・電話番号をAIに貼り付けてしまった事例が後を絶ちません。

02

社内機密情報の
流出リスク

未発表のプロジェクト名や顧客情報、財務データをChatGPTへ送信してしまうリスクがあります。

03

認証情報・APIキーの
誤入力

デバッグ目的でAPIキーやパスワードをAIに貼り付け、意図せず外部に送信してしまうケースがあります。

04

ポリシー遵守状況の
把握が困難

AI利用規程を整備しても、各社員が実際に守っているかどうかの確認が難しい状況です。

Features

主な検知機能

多角的な検知ロジックで、あらゆる情報漏洩パターンに対応します。

個人情報（PII）検知

氏名・住所・電話番号・メールアドレスなどの個人情報を、固有表現認識（NER）と正規表現の組み合わせで検知します。

正規表現 + NER

金融情報検知

クレジットカード番号・銀行口座番号をLuhnアルゴリズムと正規表現で検知します。誤検知を抑えた高精度な判定が可能です。

Luhn アルゴリズム

認証情報・APIキー検知

AWS・GitHub・Slack・OpenAIなどの主要サービスのAPIキー形式を網羅したパターンマッチングで、認証情報の送信を防ぎます。

パターンマッチ

社内機密辞書

未発表プロジェクト名・顧客名・内部コードなど、組織固有の機密ワードをカスタム辞書として登録・管理できます。

カスタム辞書

完全ローカル処理

すべての検知処理は各PCのローカル環境内で完結します。検知データが社外に送信されることは一切ありません。

オフライン対応

画像OCR検査（予定）

書類・スクリーンショットなどの画像を添付した際も、OCRでテキストを抽出して同一の検知ロジックを適用します。

Tesseract OCR

Architecture

導入パッケージ

小さく始めて確実に拡張できる、2つのパッケージをご用意しています。

スタンダード

Chrome 拡張機能パッケージ

Web上のAIツールを対象としたスタートプラン

まずWebブラウザ上のAIツールへの情報漏洩をカバーするスタートプランです。インストールは拡張機能の追加のみで完結し、データはブラウザ外に出ません。

  • ChatGPT（Web）に対応
  • Claude.ai（Web）に対応
  • Gemini（Web）に対応
  • フォーム送信を一時停止して検査
  • 検知時に警告ダイアログを表示
  • ローカルモデル（ONNX / TF.js）で処理
プロ

ハイブリッドパッケージ

CLI・APIツールまで含めた完全カバープラン

スタンダードの全機能に加え、ローカルプロキシを組み合わせることでCLIツール・API呼び出しも一元管理できるプランです。

  • スタンダードの全機能を含む
  • Claude Code（CLI）にも対応
  • API直叩きスクリプトにも対応
  • spaCy / presidioによる高精度検知
  • 検知ログの記録・レポート機能
  • 社内PC展開の自動化スクリプト付属
