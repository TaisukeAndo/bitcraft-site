# Googleフォーム質問仕様書（コピペ用）

`apply/index.html` の申込フォームに対応する、実際に作成すべきGoogleフォームの質問一覧。上から順にGoogleフォームの編集画面へそのまま入力していけば完成する。

**重要: 質問タイトルは一字一句このとおりに入力すること。** 特に「お名前」「メールアドレス」の2つは `gas/Code.gs` の `CONFIG.NAME_FIELD` / `CONFIG.EMAIL_FIELD` が文字列一致で参照しており、全角/半角・句読点・表記が1文字でもずれると自動返信メールが静かに送信されなくなる（エラーにもならないため気づきにくい）。

作成後にやること: 各質問の「⋮」→「事前入力したリンクを取得」で `entry.xxxxxxxxx` を確認し、`apply/index.html` の対応する `name` 属性と `apply/apply-script.js` の `GOOGLE_FORM_URL` に反映する（現在は `claude-code-1day` からコピーしたダミーIDが入ったままなので、必ず実際の値に差し替える）。

**「その他」を選択できる質問（5・7・9）について:** Googleフォームの選択肢一覧に手入力で「その他」を追加するのではなく、ラジオボタン/チェックボックス質問の編集画面下部にある **「'その他' を追加」** トグルを使うこと。これにより「その他」を選んだ回答者に自由記述欄が自動的に表示される。この場合、事前入力リンクで取得できる値は2つに分かれる:
- 選択肢そのものの `entry.xxxxxxxxx`（「その他」を選ぶと値は `__other_option__` になる）
- 自由記述欄の値が入る `entry.xxxxxxxxx.other_option_response`（末尾に `.other_option_response` が付いた別ID）

サイト側（`apply/index.html`）は既にこの2つを前提にマークアップ済みなので、実フォーム作成後はこの2種類のIDをそれぞれ対応する箇所に反映するだけでよい。

## 質問数について

全16問。うち必須は6問（お名前・メールアドレス・ご職業ご所属・AI活用頻度・解決したい課題・個人情報同意）。既存の `claude-code-1day` 申込フォーム（15問）と同水準で、B2B向けに「会社名・団体名」「Google/Microsoft利用サービス」「自動化したい業務領域」を追加した構成。参考として提示された吉井氏の「生成AI基礎」事前アンケート（9問・簡易版）は有料セミナーの正式申込ではなく事前ヒアリング目的のフォームのため、電話番号・会社名・同意チェックを持たない。本フォームは有料（5,500円）・少人数（定員10名）の正式申込のため、連絡先確認と同意取得を省略しない現行構成を維持する。
