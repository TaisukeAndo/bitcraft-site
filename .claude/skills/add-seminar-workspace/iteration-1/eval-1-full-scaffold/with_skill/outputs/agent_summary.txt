- Googleフォームは未作成のため、apply-script.js の GOOGLE_FORM_URL は

  明示的なプレースホルダーのままです。フォーム作成後、以下の対応が必要です:
  1. apply-script.js の GOOGLE_FORM_URL を実際の formResponse URL に差し替える

     質問ごとの entry ID に置き換える（質問文・項目数はテンプレートのIDのまま流用しているため、
     フォームの質問文・選択肢は本ファイルの記載内容に合わせて作成すると差し替えが楽です）
