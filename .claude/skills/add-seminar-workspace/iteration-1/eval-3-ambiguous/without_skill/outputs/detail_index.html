Home / Seminar / デザイン思考ワークショップ
2027年3月頃開催予定（日程調整中）

「良いアイデア」より先に、
「解くべき問題」を見つけよう。

思いつきのブレストで終わらせない。ユーザーの声を観察し、本質的な課題を定義し、
簡易プロトタイプを作って検証する――デザイン思考の一連のプロセスを、
1日で実際に手を動かしながら体験するワークショップです。

参加に興味がある方はこちら
参加費 未定（決定次第公開） 定員 未定（少人数制を予定）

TARGET

こんな方に届けたい

  • 会議で「アイデア出し」をしても、結局いつもと同じ発想しか
    出てこないと感じている方

  • 新しい商品・サービス・企画を考えたいが、
    何から手をつければいいか分からない方

  • 「ユーザー視点で考えよう」と言われても、
    具体的にどう考えればいいか分からない方

  • 頭の中の思いつきを、実際に形にして試すところまで
    一気にやってみたい方

BENEFITS

ワークショップで得られること

01

「課題の見つけ方」が変わる

観察・共感（Empathize）から、本当に解くべき問題を定義（Define）するまでの視点をハンズオンで体得します。

02

「アイデアの広げ方」が変わる

発散と収束を行き来する型を使い、限られた時間の中でも質の高いアイデアにたどり着く方法を学びます。

03

「思いつき」を形にする体験

簡易プロトタイプを実際に作り、その場でフィードバックを受けて磨き込むサイクルを体験します。

04

明日から使えるフレームワーク

自分の業務・企画に持ち帰って、すぐに実践できるデザイン思考の型を手元に残します。

終了
